# Архитектура MVP

1. `MarketDataProvider` получает OHLCV и приводит данные к единой схеме.
2. `features.py` рассчитывает признаки отдельно по каждому тикеру и создаёт будущую цель только для обучения.
3. `GrowthModel` обучается на хронологически упорядоченных наблюдениях и сохраняется локально.
4. `SignalService` ранжирует последний доступный срез, штрафуя чрезмерную волатильность.
5. `risk.py` ограничивает размер позиции одновременно по объёму капитала и допустимому убытку.
6. `PaperBroker` хранит виртуальный баланс и позиции.
7. FastAPI предоставляет единый интерфейс для будущего веб-приложения.
