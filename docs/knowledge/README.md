## Как пополнять

- Искать URL/ID во всём репозитории перед добавлением. По существующему источнику дополнять текущую заметку.
- Сохранять короткий конспект, первичный URL, дату, таймкоды и способ проверки. Отделять слова автора, выводы ИИ и собственную проверку.
- Этот репозиторий публичный: сюда подходят публичные источники и обобщённые исследовательские материалы; данные личного счёта, операции пользователя, токены и доступы сюда не помещать.
- Заметки не являются торговыми сигналами, реализованными функциями или разрешением на сделки. Новую функциональность обсуждать и проверять в рамках существующей архитектуры.
