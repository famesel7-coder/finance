# Работа с доходом российского портфеля

Отправная точка — действующие активы и денежный поток по фактическим операциям. Для сравнения
стратегий нужны дивиденды после удержаний, полная доходность, максимальная просадка, оборот
и вклад крупнейших эмитентов.

## Сверка и журнал

Установить зависимости проекта по [README](../../README.md). Запускать команды из корня
репозитория. Для подключения использовать настроенную запись Связки ключей Mac.

```sh
python -m app.portfolio_journal sync --keychain-service SERVICE --keychain-account ACCOUNT
python -m app.portfolio_journal summary --days 365
python -m app.portfolio_journal valuations --days 90
```

На других системах команда импорта использует `TINVEST_TOKEN` из защищённого окружения.
На macOS журнал проверяет сертификат банка через системное хранилище доверия.
Импорт читает открытые счета, портфели и выполненные операции через API. Записи операций
обновляются по идентификаторам счёта и операции. Повторный импорт сохраняет новую оценку
портфеля и учитывает каждую операцию один раз. Суммы дивидендов, налогов и комиссий
агрегируются по валютам. Итог за период проверять по началу покрытия и дате снимка,
которые выводит команда `summary`. Команда `valuations` читает последний снимок за каждую
дату по Москве. Она показывает стоимость счетов. Для оценки доходности между снимками
учитывать движения денег и переводов.

Файл `data/portfolio.sqlite3` предназначен для локального использования и исключён из Git.
Котировки и индекс полной доходности брать из [ISS Мосбиржи](https://www.moex.com/a2193).
Дивиденды сверять по [операциям Т‑Инвестиций](https://developer.tbank.ru/invest/api/operations-service-get-operations-by-cursor),
[корпоративным событиям](https://developer.tbank.ru/invest/api/instruments-service-get-dividends)
и решениям эмитентов.

## Проверка сценариев

1. Сравнить удержание текущих весов, реинвестирование зачисленных дивидендов и небольшое
   перераспределение между теми же активами. Оценить концентрацию и снижение выплат
   у крупнейших плательщиков. Параметры реальных сделок брать из указаний владельца.
2. Зафиксировать дату оценки и версию данных. В историческом сравнении использовать только
   доступные к дате сигнала раскрытия. Применять лоты, учёт сплитов, спреды и фактический
   тариф. Для тарифа «Инвестор» начальный расчёт комиссии по акциям использует 30 б.п.
   на каждую сторону сделки. Проверить применимый тариф по [условиям брокера](https://www.tbank.ru/invest/help/brokerage/account/get-bs/tariff/).
   Параметр `TRANSACTION_COST_BPS` задаёт комиссию полного оборота. `EXECUTION_SPREAD_BPS`
   задаёт предполагаемые расходы на спред отдельно.
3. Проверить параметры на последующих отрезках истории и в бумажном режиме. Сравнить
   полную доходность с удержанием и с [MCFTR](https://www.moex.com/a5792), приводя
   результаты к сопоставимому учёту налога. Бэктест ранжирования в Finance Radar
   использует динамику цен. Для дивидендного сравнения добавить выплаты и их календарь.
4. Оценивать переход к реальным действиям после сравнения денежного потока и просадки
   с базовым вариантом и согласования суммы и лимита потерь.

## Запуск портфельного сравнения

```sh
python -m app.portfolio_replay data/scenario.json
python -m app.portfolio_replay data/scenario.json --quotes data/candles.csv --benchmark data/mcftr.csv
```

| Поле JSON | Значение |
| --- | --- |
| `as_of`, `until`, `cash_rub` | Дата стартового снимка с ценами закрытия, конец периода и свободные рубли |
| `positions` | Текущие тикеры с `shares` и `lot` |
| `dividends` | Тикер, последний день с правом на выплату `eligible_on`, день зачисления `paid_on` и чистый дивиденд на акцию `net_per_share` |
| `splits` | Тикер, день вступления в силу `effective_on`, коэффициент `new_shares` / `old_shares`, при необходимости новый размер `lot` |
| `reinvest_in` | Подмножество действующих бумаг для покупок за зачисленные дивиденды |
| `rebalance` | Дата решения `decided_on`, списки `sell` и `buy`, лимит продаж `budget_rub` |
| `commission_bps`, `spread_bps` | Комиссия на сторону сделки и полный модельный спред |

Сделки считаются по открытию следующей доступной сессии целыми лотами. Дивиденды становятся
доступны для покупки после даты зачисления. Индекс MCFTR загружается через ISS вместе
со свечами. Для офлайн-прогона CSV котировок содержит `date,ticker,open,close`, CSV индекса
содержит `date,close`. Начальная и финальная даты сравнения должны быть представлены в обоих источниках.

Расчёт показывает указанные чистые дивиденды, полную доходность, дневную просадку,
расходы и оборот. Для оценки налога на продажу нужны учётная цена и налоговый режим
счёта. Перед историческим сравнением сверить начальные количества, выплаты и корпоративные
действия на каждую дату.
