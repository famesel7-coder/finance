# Отчётность для дивидендного портфеля

1. Открыть актуальную отчётность эмитента и дивидендную политику. Зафиксировать дату
   раскрытия и период. Сопоставить фактические выплаты с результатами соответствующего года.
2. Для нефинансовых компаний проверить свободный денежный поток после инвестиций,
   долговую нагрузку и покрытие выплат. Для банков проверить прибыль и достаточность
   капитала. Отметить роль разовых выплат и поступлений.
3. Сравнить сценарии сохранения и снижения выплат в рублях на текущую позицию.
   Учитывать концентрацию по компании, отрасли и источникам дивидендов.
4. Перед предложением сделки сравнить варианты с удержанием текущего состава.
   Учесть лоты, спред, комиссию и налоги по методике
   `docs/knowledge/portfolio-income.md`. Для ключевых выводов указать первичные ссылки.
