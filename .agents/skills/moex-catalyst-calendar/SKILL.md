# Календарь корпоративных событий

1. Взять список бумаг и количество из актуального снимка портфеля. Добавить другие бумаги
   в наблюдение по запросу пользователя.
2. Проверить календарь и раскрытие эмитента. Сохранить источник, дату публикации, период
   дивидендов и сумму на акцию. Зафиксировать стадию события: рекомендация, утверждение,
   закрытие реестра или зачисление. Сверить последний день покупки с торговым календарём
   и актуальным режимом расчётов, когда дата нужна для сделки.
3. Рассчитать сумму на текущее количество акций до налога. Для рекомендаций указать условия
   выплаты. Подтвердить фактический приход по журналу Т‑Инвестиций.
4. Дать короткий список ближайших событий по московскому времени со ссылками на эмитентов.
   Схему сверки и источники взять из `docs/knowledge/portfolio-income.md`.
