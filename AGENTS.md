# Finance Radar

- Для задач по реальному портфелю открой [методику дохода по портфелю](docs/knowledge/portfolio-income.md).
  В ней описаны источники, сверка выплат и критерии проверки стратегий.
- Используй навыки из `.agents/skills/` для обновления данных, календаря корпоративных
  событий и разбора отчётности. Работай с локальной копией журнала через
  `python -m app.portfolio_journal`.
- Для чтения счёта используй существующий клиент Т‑Инвестиций. Параметры подключения
  получай из разрешённого локального окружения. Храни снимки и операции в `data/`.
- Сохраняй в публичном Git только код, публичные источники и обобщаемую методику.
  Секреты, идентификаторы брокерских счетов, остатки и операции храни вне Git.
- Проверяй гипотезы на истории и в бумажном режиме. Запросы на чтение и расчёты
  сами по себе не дают полномочий выставлять заявки.
