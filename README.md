# Finance Radar

Веб-сервис для количественного анализа акций Московской биржи: он загружает официальные дневные свечи MOEX, оценивает вероятность роста на коротком горизонте, показывает объясняющие факторы, собирает модельный портфель и проверяет стратегию на истории.

> Программа не обещает прибыль и не является индивидуальной инвестиционной рекомендацией. Любая модель ошибается, а стоимость акций может снизиться. Реальные сделки по умолчанию заблокированы.

## Возможности

- готовая русскоязычная панель в браузере;
- 22 ликвидные российские компании из разных отраслей;
- котировки через официальный [MOEX ISS](https://www.moex.com/a2193);
- модель `RandomForestClassifier` и резервный объяснимый скоринг;
- признаки импульса, тренда, объёма, волатильности, просадки и пробоя;
- модельный портфель для осторожного, сбалансированного или агрессивного профиля;
- хронологический out-of-sample бэктест без перекрывающихся периодов;
- бумажный брокер для безопасной симуляции;
- защищённый адаптер Т‑Инвест с sandbox-режимом и явным подтверждением заявок;
- проверка лимита вывода через API Т‑Инвест.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
uvicorn app.api:app --reload
```

Откройте панель: `http://127.0.0.1:8000`. Интерактивная документация API: `http://127.0.0.1:8000/docs`.

## Основные API

```bash
# Рейтинг стандартной выборки MOEX
curl -X POST http://127.0.0.1:8000/scan \
  -H "Content-Type: application/json" \
  -d '{"tickers":[],"market":"moex","period":"2y","top_n":7}'

# Рейтинг и портфель одним запросом (этот метод использует веб-панель)
curl -X POST http://127.0.0.1:8000/analysis \
  -H "Content-Type: application/json" \
  -d '{"tickers":[],"market":"moex","period":"2y","top_n":7,"capital":500000,"risk_profile":"balanced"}'

# Модельный портфель на 500 000 рублей
curl -X POST http://127.0.0.1:8000/portfolio/recommend \
  -H "Content-Type: application/json" \
  -d '{"tickers":[],"market":"moex","period":"2y","top_n":7,"capital":500000,"risk_profile":"balanced"}'

# Проверка стратегии на невидимом для модели участке истории
curl -X POST http://127.0.0.1:8000/backtest \
  -H "Content-Type: application/json" \
  -d '{"tickers":[],"market":"moex","period":"5y","top_n":7}'
```

Модель прогнозирует достижение доходности `TARGET_RETURN` через `FORECAST_HORIZON_DAYS`. Порог и горизонт задаются в `.env`. Результаты бэктеста учитывают примерные транзакционные расходы, но не учитывают все возможные проскальзывания, налоги и корпоративные события.

## Т‑Инвест

Для подключения создайте токен только в официальном кабинете брокера и запишите его локально в `.env`:

```dotenv
TINVEST_TOKEN=...
TINVEST_ACCOUNT_ID=...
TINVEST_SANDBOX=true
ALLOW_LIVE_TRADING=false
```

Секреты нельзя коммитить в GitHub. Заявка не будет отправлена, пока одновременно не включён `ALLOW_LIVE_TRADING`, а API-запрос не содержит точную строку подтверждения `EXECUTE_LIVE_ORDER`. Сначала используйте sandbox и длительное бумажное тестирование.

API Т‑Инвест позволяет запросить доступную для вывода сумму, но **не выполняет вывод с брокерского счёта**. Поэтому Finance Radar показывает лимит, а вывод пользователь подтверждает вручную в приложении или личном кабинете Т‑Банка. Это ограничение описано в [официальной справке Т‑Инвест](https://developer.tbank.ru/invest/services/accounts/faq_transfers).
