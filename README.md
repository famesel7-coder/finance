# Finance Signal Service

Открытая основа сервиса, который ранжирует ликвидные акции по вероятности роста на коротком горизонте, проверяет стратегию на истории и формирует виртуальные сделки.

> Проект не обещает доходность и не является инвестиционной рекомендацией. Реальные сделки по умолчанию отключены.

## Что уже есть

- загрузка дневных котировок через Yahoo Finance;
- технические признаки без использования будущих данных;
- ML-модель `RandomForestClassifier` для прогноза положительной доходности;
- резервный детерминированный скоринг, если модель ещё не обучена;
- рейтинг бумаг с вероятностью роста, ожидаемым движением и факторами сигнала;
- простой walk-forward бэктест с комиссиями;
- контроль размера позиции и лимита риска;
- виртуальный брокер `PaperBroker`;
- REST API на FastAPI;
- Docker и автоматические тесты.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
uvicorn app.api:app --reload
```

Документация API: `http://127.0.0.1:8000/docs`.

## Пример сканирования

```bash
curl -X POST http://127.0.0.1:8000/scan \
  -H "Content-Type: application/json" \
  -d '{"tickers":["AAPL","MSFT","NVDA","AMZN"],"period":"2y","top_n":3}'
```

## Обучение модели

```bash
curl -X POST http://127.0.0.1:8000/train \
  -H "Content-Type: application/json" \
  -d '{"tickers":["AAPL","MSFT","NVDA","AMZN","META","GOOGL"],"period":"5y"}'
```

Модель прогнозирует, будет ли доходность через `FORECAST_HORIZON_DAYS` выше `TARGET_RETURN`. Эти параметры задаются в `.env`.

## Бэктест

```bash
curl -X POST http://127.0.0.1:8000/backtest \
  -H "Content-Type: application/json" \
  -d '{"tickers":["AAPL","MSFT","NVDA","AMZN"],"period":"5y","top_n":2}'
```

## Безопасность

- `ALLOW_LIVE_TRADING=false` установлен по умолчанию;
- ключи брокера нельзя добавлять в GitHub;
- перед реальными сделками стратегия должна пройти out-of-sample и paper-тестирование;
- одна позиция ограничена `MAX_POSITION_PCT`;
- решения API содержат факторы сигнала, чтобы их можно было проверить.

## Российский рынок

Текущий источник данных удобен для прототипа на американских тикерах. Для Московской биржи потребуется добавить отдельный `MarketDataProvider` и адаптер брокера Т-Банка. Аналитическое ядро, модель и риск-контроль останутся теми же.

## Происхождение архитектуры

Структура проекта вдохновлена идеями [FinRL-X](https://github.com/AI4Finance-Foundation/FinRL-Trading): разделение данных, стратегии, бэктеста, исполнения и риск-контроля. Код данного репозитория написан отдельно; исходный код FinRL-X не копировался. Подробности — в [ATTRIBUTION.md](ATTRIBUTION.md).
